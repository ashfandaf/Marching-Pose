# Harmoni Drumband & Kostum Yogyakarta - Landing Page

Landing page modern dan responsif untuk persewaan alat marching band, drumband anak & remaja, serta kostum seragam karnaval/parade di Daerah Istimewa Yogyakarta.

## 🚀 Fitur Utama
- **Hero Section**: Headline representatif, statistik terpercaya (500+ event, 120+ sekolah), tombol WhatsApp, dan preview produk best-seller.
- **Dedikasi Seni Musik Sejak 2012**: 4 kartu nilai keunggulan (Standar Nasional, Kostum Higienis Setrika Uap, Workshop & Fitting DIY, SPK Resmi BOS).
- **Katalog Produk & Tarif Sewa**: Filter kategori (Semua, Alat Musik, Kostum & Seragam) dengan harga harian/set dan modal spesifikasi detail.
- **Testimoni Terpercaya**: Ulasan bintang 5 dari kepala sekolah, pembina seni, dan pelatih marching band.
- **Informasi Workshop & Peta Interaktif**: Alamat lengkap di Jl. Ringroad Selatan Sewon Bantul, jam buka, kontak cepat, dan navigasi Google Maps.
- **Kalkulator / Estimasi Biaya Interaktif**: Simulasi biaya sewa berdasarkan durasi hari dan kuantitas unit, otomatis menghitung diskon paket sekolah (10%) serta tombol ekspor ke WhatsApp.
- **Integrasi WhatsApp Langsung**: Pesan otomatis dengan rincian unit yang ingin disewa.

## 🛠️ Teknologi yang Digunakan
- **React 18**
- **Vite**
- **Tailwind CSS**
- **Lucide React** (Icons)

## 💻 Cara Menjalankan di Lokal

1. Buka terminal di folder proyek (`d:\Marching Pose`):
   ```bash
   npm install
   ```

2. Jalankan development server:
   ```bash
   npm run dev
   ```

3. Buka browser pada URL:
   `http://localhost:5173/`

4. Untuk membuat build produksi:
   ```bash
   npm run build
   ```
